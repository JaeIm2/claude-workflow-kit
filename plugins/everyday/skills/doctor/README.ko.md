# doctor — 설정 점검

[English](README.md) | 한국어

claude-workflow-kit가 제대로 설정돼 있고 동작하는지 점검해서, 항목마다 정상인지, 뭐가 문제인지, 어떻게 고치는지 알려주는 Claude Code 스킬. 읽기만 한다. 고치자고 했을 때만 설정이나 개인 규칙 파일을 수정한다.

## 필요한 것
- `everyday` 플러그인이 설치된 Claude Code ([루트 README](../../../../README.ko.md) 참고)

## 쓰는 법
- `/everyday:doctor`, "설정 점검", "왜 안 되지" — 전체 점검
- "weekly-report 스킬이 왜 안 떴지?" — 입력한 말과 그 스킬의 호출 문구를 비교해서 어떻게 말하면 되는지 알려준다
- "다른 사람한테 보낼 진단 결과 만들어줘" — 같은 점검 결과를 이름·경로·사내 주소·토큰을 뺀 복사용 요약으로 만든다. 어디에도 보내지 않고, 복사는 직접 한다

## 점검 항목
1. **공용 설정** (`~/.claude/workflow/config.md`) — Common 항목이 영어 라벨 그대로 있는지, 설치한 스킬의 섹션이 빠짐없는지. 아직 아무것도 설정하지 않았다면 한 번에 설정할지 물어본다
2. **연결된 도구** — 업무 관리 도구와 기록 문서용 도구가 이 세션에서 실제로 쓸 수 있는지, 아침 브리핑에 허용된 도구가 전부 읽기 전용인지
3. **작업 기록** — 할 일 목록과 notes 폴더가 있고 읽을 수 있는지
4. **개인 규칙** — 스킬별 규칙 개수, 서로 충돌하거나 승인 절차를 건너뛰려는 규칙, 보내지 않은 제안 개수
5. **아침 브리핑** (macOS, 설정한 경우만) — 스크립트 위치, 예약 작업 등록 여부, `YOUR_NAME` 수정 여부, 마지막 실행 결과
6. **dev 플러그인** (설치한 경우만) — push 확인 훅이 켜져 있는지, git 호스팅 CLI에 로그인돼 있는지, 저장소 경로가 있는지, 워크트리 설정이 안전한지
7. **플러그인 버전** — 설치된 버전과 최신 버전, 업데이트 명령

## 참고
- 설치·업데이트·로그인·등록은 직접 하지 않는다. 실행할 명령만 알려준다.
- 스킬이 떠야 할 말이었는데 안 떴다면 그 문구를 `~/.claude/workflow/suggestions.md`에 추가해서, 다른 제안과 같이 보낼 수 있게 한다.
